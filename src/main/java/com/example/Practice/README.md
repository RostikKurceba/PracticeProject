Вимоги

Функціональні
1. Реєстрація користувачів. Система повинна дозволяти студентам і викладачам створювати облікові записи.
2. Вхід у систему. Система повинна дозволяти користувачам входити до свого облікового запису за допомогою електронної пошти та пароля.
3. Пошук викладачів. Студент повинен мати можливість шукати викладачів за назвою навчальної дисципліни.
4. Перегляд інформації про викладача. Студент повинен мати можливість переглядати інформацію про викладача та його доступний час для консультацій.
5. Запис на консультацію. Студент повинен мати можливість записатися на вільний час консультації та переглядати свої записи.
Нефункціональні
1. Зручність використання. Інтерфейс системи повинен бути зрозумілим і простим у використанні.
2. Сумісність. Система повинна працювати в сучасних веббраузерах, наприклад Google Chrome та Microsoft Edge.
3. Швидкодія. Основні операції системи, наприклад пошук викладачів, повинні виконуватися не довше ніж за 2 секунди за нормального навантаження.
4. Безпека. Система повинна захищати облікові записи користувачів і не дозволяти стороннім особам отримувати доступ до чужих даних.
5. Надійність запису. Система повинна запобігати запису кількох студентів на один і той самий зайнятий час консультації.
